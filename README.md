## 🚀 Projets sélectionnés

### [Hackathon IA temps réel – Pioneers @ Station F](https://github.com/loanper/pioneers-hackathon-vertex)
> **Stack :** `Python` `FastAPI` `React` `TypeScript` `GCP` `Vertex AI` `Gemini` `Docker`
* **Pipeline IA audio :** traitement de journaux vocaux avec transcription, extraction d’émotions et génération de rapports HTML/PDF.
* **Architecture cloud :** intégration de Google Cloud, Cloud Storage, Speech-to-Text, Eventarc et services IA.
* **Application complète :** backend FastAPI + frontend React/TypeScript avec interface utilisateur dédiée.
* **Industrialisation :** documentation, scripts de déploiement et exécution end-to-end sur une architecture modulaire.

### [Pipeline DVF Data Lake](https://github.com/loanper/Pipeline_DVF_DataLake)
> **Stack :** `Python` `Pandas` `DuckDB` `SQL` `Data Lake` `BI`
* **Pipeline multi-hop :** structuration des données en couches raw, staging et curated pour fiabiliser l’analyse.
* **Data warehouse local :** création d’un entrepôt DuckDB pour l’exploration analytique et les requêtes BI.
* **Valorisation de données :** génération d’extractions prêtes à l’emploi pour Excel, Power BI ou Tableau.
* **Approche Data Engineering :** séparation claire entre ingestion, nettoyage, modélisation et exploitation.

### [Azure DataFlow Intelligence](https://github.com/loanper/Azure-DataFlow-Intelligence)
> **Stack :** `Python` `Azure Functions` `Azure Blob Storage` `Azure Document Intelligence` `Pandas`
* **Architecture serverless :** déclenchement automatique du traitement lors du dépôt d’un PDF dans le stockage Azure.
* **Extraction intelligente :** utilisation d’Azure Document Intelligence pour analyser la structure et le contenu des documents.
* **Pipeline événementielle :** chaînage entre stockage, fonction cloud et transformation des données.
* **Déploiement cloud :** projet conçu pour une exécution scalable sans gestion d’infrastructure dédiée.

### [Pipeline Spark Distribuée](https://github.com/loanper/Pipeline-Spark)
> **Stack :** `Apache Spark` `Docker` `MinIO` `Python` `Big Data`
* **Traitement massif :** analyse distribuée d’un dataset de plusieurs millions de lignes avec Spark.
* **Architecture moderne :** séparation entre calcul distribué et stockage objet de type S3 via MinIO.
* **Reproductibilité :** environnement entièrement conteneurisé avec Docker pour faciliter le déploiement.
* **Vision Data Platform :** projet orienté infrastructure Big Data et montée en charge.

### [Eco-Predict](https://github.com/loanper/Eco-Predict)
> **Stack :** `Python` `XGBoost` `Optuna` `Scikit-learn` `FastAPI` `Joblib`
* **Prédiction énergétique :** modélisation de la consommation énergétique de logements sur plusieurs départements.
* **Pipeline ML avancée :** feature engineering, nettoyage métier et optimisation du modèle avec Optuna.
* **Déploiement prêt API :** export du pipeline entraîné au format `.joblib` pour intégration backend.
* **Projet end-to-end :** articulation entre data preparation, modélisation et mise en production du modèle.
